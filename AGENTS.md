# Project instructions

- Backend code lives in DanielLocksStorage. User-authorized source materials are preserved in sibling DanielLocksMaterials. Do not access DanielLocksStorageCLD.
- Never start a local backend, frontend, watch process, preview server, or HTTP test listener without explicit user permission. Build-only and non-listening checks are allowed.
- Never print secrets or commit .env, chat histories, email captures, or client documents.
- Widget, Maintenance, and each product code have separate sessions and histories. They share AI/backend services, not one conversation.
